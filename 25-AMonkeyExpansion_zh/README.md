# A Monkey Expansion 简体中文翻译 Notes

## 一句话定位
A Monkey Expansion (Continued) 的简体中文翻译（纯翻译 mod）。

## 关键要点
- 纯翻译，无 C#；翻译内容在 `Common/Languages/ChineseSimplified (简体中文)/`。
- 用「提取翻译（Extract translation）」mod 辅助翻译。
- 依赖 `zal.monketime`（A Monkey Expansion (Continued)）。
- 注意：`LoadFolders.xml.bak` 为模板残留（引用不存在的 1.3 等目录），可清理。
